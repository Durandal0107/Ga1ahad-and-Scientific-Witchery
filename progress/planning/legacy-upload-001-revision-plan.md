# 五句歌词短片：修改方向

评审对象：[用户上传的上一版视频](../versions/legacy-upload-001/video.mp4)。结合 [历史对话](../context/old.md#L3569) 的最后一轮明确反馈与后续讨论整理。画面总览见 [overview.jpg](../versions/legacy-upload-001/review/overview.jpg)，转场见 [transitions.jpg](../versions/legacy-upload-001/review/transitions.jpg)，冲击逐帧见 [impact.jpg](../versions/legacy-upload-001/review/impact.jpg)。

本轮任务是分析修改方向。下文区分实际画面、用户明确要求与建议方案；没有把旧讨论中的建议当成已经确认的设计。

## 核心目标

让线条的变化直接表现女巫与侍从的关系：复生与回应、靠近与束缚、短暂安定、突发冲击及留下的后果。歌词书写、人物意象和转场应共享动作，画面每次变化都能看出前因后果。

现有值得保留的方向是：深色/米白/红色的克制配色，手写叙述词与较大情绪词的区别，`Rise` 的上升方向，以及 `see / kill` 的语义冲突。它们需要加强辨识、受力与阅读顺序。

## 下一版的六项主要修改

### 1. 先让人物意象被认出来，再进入抽象变化

用户已经明确要求人物意象，并明确无需画具体两人。候选方案仍可采用“女巫的帽形转针线、侍从的裂剑与护手”，但这一组合尚未最终确认。

无论采用哪组符号，都应先有一次清晰、足够大的识别，随后在动作中持续保留特征。现在的剑虽存在，却像被放进器皿的插图；下一版应让它撑开连接、复原后挺直，或在亲昵时主动靠近。女巫一端则通过接合、包围、收拢等动作建立身份。

保留双方都能牵引、回应和抵抗的情感方向；不要让针始终代表攻击、剑始终代表受害。角色具体符号和动作归属保持可讨论。

### 2. 让线条承担连续动作，删掉无法解释用途的线

每段保留的线都应能归入书写、造型、连接或传力。一个词的收笔应延伸成图形或连接，上一幕的轮廓应成为下一幕的材料。

重新设计现在的双圆形结构；不能只把圆放大或加注释。若用器皿，应保持瓶口/倾倒/流动等可辨认动作；若用包围，应能看到它在包围谁、谁在回应。卷曲线或下划线不能只为了填满画面。

### 3. 把转场改成同一个动作的继续

建议沿一个共同连接点推进：修补裂口 → 连接收紧 → `Rise` 提起结构 → 连接松开、留白展开 → `kill` 使刚打开的空间突然收缩。

用镜头跟随和形状接续保持连续；黑白底色可继续使用，但应由线转面或物体运动带出。不要保留现版独立矩形扫屏作为主要转场机制。

### 4. 字体分工更明确，歌词按演唱退出

叙述词保留连续书写，但拉开词间距离，减少每个字母都带复杂回笔的情况。情绪词则以少量定制的笔画、尺度和受力变化承担重点，每个节拍只有一个主要阅读焦点。

用户明确要求一条线歌词在该句唱完后消失或淡化。前两句只在实际演唱重叠时短暂并存；退出可沿收笔回收或快速淡化，只留下下一动作需要的连接。

`see / kill` 短暂共存、`again` 固定是旧助手方案：可以保留作语义冲突实验，但不能因此长时间保留整句。最终共存时长要服从清晰度及用户最新退场要求。

### 5. 重做 kill 的时间与后果

现版已有大字、滑入、残影及暗红闪动，优先改变这些动作的配合，而不是继续堆叠效果。

建议先试“红闪后直接落位”：保留 `see` 的安定窗口，在实际 `kill` 起音附近给全画面一次偏红闪动，随后直接出现；另一备选是只用极少帧完成插入。约 2 帧红闪只是初始试验参数，不能先于起音核对锁定。

落位后让共同连接处骤缩，剑身接合处错开，或某段笔画无法重新闭合；给受影响对象一次短促反作用，随后迅速停稳。字与图形必须一起发生变化。保留 `darling` 与 `kill` 字形的亲缘关系，可让同一种亲密笔迹突然变得压迫。

### 6. 声画节拍与情感层次一起安排

下一轮制作前核对五句和关键词实际起止，尤其是两条声线重叠、`Rise`、`kill`。本轮做了音频技术测量，没有逐词听审，因此不判定现版精确对齐或错位。

建议让情绪依次经过“唤醒—回应与靠近—安定—冲击—后果”。红色可先用于修补和亲昵，再在冲击处占据画面；不要始终用红色固定代表某个角色或危险。

## 按五句组织下一版动作

| 歌词段 | 主要动作与焦点 | 接续及退场 |
| --- | --- | --- |
| The magical potion… | 建立双方意象；书写牵出修补，侍从一端主动回应；`reanimation` 与结构接合共用动作。 | 保留修补连接，第一句唱完即退出；下一句由连接继续生成。 |
| Bittersweet… | 书写与颜色从连接扩展，`euphoria` 膨胀造成挤压；甜美与束缚发生在同一动作中。 | 限制轮廓数量，留出主体；收紧连接以准备提拉。 |
| Rise…my darling | 先绷紧、再提起有重量的结构，`Rise` 有过冲；亲昵文字靠近时，侍从也主动靠近或抵住。 | 镜头沿受力方向稍后跟随；该句结束，连接松弛并带走文字。 |
| So I can see… | 首次真正打开空间；完整文字与双方靠近的关系同处清楚的构图。 | 留出短暂安定，撤去无作用轮廓，为冲击提供对比。 |
| So I can kill… | 红闪后直接落位或极快插入；共同连接处和刚修复的结构承受变化。 | 以仍连接却无法恢复原状的结果收尾，迅速停稳；控制旧字残留。 |

这些动作是根据既有反馈整理的建议分镜，不是已确认或已制作的第三版。

## 制作顺序与通过标准

1. 先核对起止时间，画出角色意象及连接关系；确认不依赖说明文字也能理解画面。
2. 做低清运动稿，优先验证双方动作、两次转场、歌词退出及 `kill` 的突然性和后果。
3. 再精修字形、色彩与线条，输出高清并检查完整音视频。

检查时逐项判断：是否能辨认双方；每段线是否有用途；连接能否跨转场被追踪；唱完的句子是否及时退出；`kill` 是否改变对象而非只改字的位置；停稳后的结尾是否仍有可读的关系与结果。

## 本轮验证范围

实际文件为 1920×1080、30 fps、384 帧、12.8 秒，H.264/AAC 双声道 48 kHz；完整解码退出码 0。FFmpeg EBU R128 测量约 −13.9 LUFS，真峰值约 −6.6 dBTP。本轮检查总览、转场抽帧与冲击连续帧；未进行逐词听审或新版本制作。技术参数已基本符合项目要求，修改重点在画面组织和动作表达。
