# 项目进度

本目录用于在不同对话或云环境之间继续本项目。开始下一轮工作前，先阅读 [效果要求与修改记录](requirements.md)，再查看下方最新版本。

## 保存位置

- `requirements.md`：固定的文字记录文档，持续补充用户希望达到的效果、反馈及每轮修改结果。
- `versions/vNNN/video.mp4`：该轮新制作的视频，版本从 `v001` 开始递增。
- `versions/vNNN/keyframes/`：从该版本视频提取的关键帧，建议用 `frame-000030.png` 等帧编号命名。
- `versions/vNNN/README.md`：该轮改动、视频参数、关键帧时间码及验证结果，链接到文字记录中对应条目。

每个视频版本应同时包含视频、关键帧和说明。保留历史版本；只有完成的实际输出才能列为已完成。临时渲染文件放在仓库外。

## 每轮更新流程

1. 将新增要求或反馈追加到 `requirements.md`，更新当前生效的要求；不要无说明地删除或改写旧要求。
2. 制作新版本，检查视频和音频，提取反映改动及主要画面的关键帧，保存到新的版本目录。
3. 在该版本说明中记录实际视频参数、关键帧时间码、验证结果和未解决的问题。
4. 更新下方版本索引，并在 `requirements.md` 的本轮记录中链接对应成果。仅文档变更或渲染未完成时明确说明没有新视频的原因。
5. 检查文件，提交并同步到 GitHub；确认远端提交后再报告同步完成。保护其他对话的更新，不强制推送。
