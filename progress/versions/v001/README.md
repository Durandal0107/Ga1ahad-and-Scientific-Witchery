# v001 — 缝合与牵引

制作日期：2026-11-01（北京时间）。状态：重做版本，等待用户评审。

本版依据用户上传的旧片与最后六项修改反馈重绘。以帽形/针线与裂剑建立双方身份，让同一条连接贯穿修补、包围、提拉、松开和再次断裂。

## 成果与工程

- `video.mp4`：带原曲声轨的正式重做版本。
- `validation/keyframes/`：从正式视频直接抽取的关键帧；帧号和时间码见 `validation/samples.json`。
- `validation/overview.jpg`、`transitions.jpg`、`impact.jpg`：全片、转场和冲击连续帧总览。
- `source/`：对应此版本的冻结源码、配置、依赖和复现脚本；后续可编辑工程在 `../../project/v001/`。
- `production/silent.mp4`：合成前的高清静音动画；同时保留响度测量和合成参数。
- `CREDITS.md`：音源、字体与字形来源。

## 本轮主要变化

1. 使用大幅帽形、针眼和带裂口的剑，取代难以辨认的双圆形结构。剑在复原后挺立，在亲昵段向连接处靠近。
2. 连接线从帽檐真实锚点出发，经过针眼抵达剑身裂口；针线的收紧、松开和拉扯参与构图。
3. 移除背景矩形扫屏，保留同一场景中的对象连续性，通过起身、牵引和松弛交接段落。
4. 连续书写增加词间空间；已唱段落按当前节拍窗口淡出，前两句交叠时错开进入位置。
5. 第 306、307 帧全画面偏红闪动，第 308 帧 `kill` 直接落位。剑的接合处随之错开，缝线退出；反作用迅速收敛。
6. `see` 仅短暂留下痕迹，结尾歌词退去，保留仍相连却受损的两个意象。

## 复现

在本目录执行，选择未使用的输出路径：

```sh
python3 source/render.py --output production/rebuild-silent.mp4
python3 source/finish.py --silent production/rebuild-silent.mp4 --output-dir rebuild
python3 source/validate.py --video rebuild/video.mp4 --output rebuild/validation
```

依赖见 `source/requirements.txt` 和 `source/toolchain.json`；共享输入为 `../../assets/source/Mili_Ga1ahad_and_Scientific_Witchery.mp4`、`../../assets/audio/five-lines-17.6-29.3.wav` 和 `../../assets/fonts/`。输入文件和源码的 SHA-256 均登记于 `../../catalog.json`。

## 验证与局限

实际验证结果写入 `validation/summary.json`、`media.json`、`frame-audit.json` 和 `decode-loudness.log`，已检查这些文件与实际成片总览。

- 正式视频：12.8 秒、1920×1080、30 fps、384 帧，H.264；2,371,827 字节。
- 声音：AAC、48 kHz、双声道；实测 −13.9 LUFS、−6.6 dBTP。
- 完整解码通过；缩小至 480×270 的逐帧前景检测无空白或触边，红闪恰为第 306/307 帧。
- 17 张高清关键帧直接来自正式视频；另有全片、16 帧转场及连续 20 帧冲击总览，供检查书写、连接、退场与快速冲击。

主要局限：双方关系仍由象征物和动作表达，完整情感层次需要长片继续建立；手写字形来自手工单线字库，个别连笔仍可精修；当前歌词时点基于原字幕与波形，未完成人工逐词听审。本版不声称达到获奖级完成度，等待用户对意象与动作效果的评价。
