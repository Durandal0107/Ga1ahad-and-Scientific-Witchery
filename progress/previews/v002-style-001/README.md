## 来源与复用

本组根据当前用户确认的纯黑实心剪影、更优雅字体及缩短双方距离的方向新生成。暖象牙底和蔓越莓红仍是本轮试验配色，未作为用户已确认颜色。

- `prompt-01-initial.txt`：第一张的完整初始生成提示词。
- `drafts/01-see-textured.png`：初始结果带有物体纹理及高光，未符合干净实心剪影方向，保留为诊断参考；不要用于正式预览。
- `prompt-02-flat-silhouette.txt`：以初始图为参考，去除物体纹理、高光及多余缝线，生成正式 01-see.png。
- `prompt-03-kill.txt`：以正式 01-see.png 为参考，改变文字、姿态、裂口与连接，生成正式 02-kill.png。
- `generation.json`：生成工具、各阶段依赖、尺寸、大小、哈希及字体/状态说明。

复用时优先调用两张正式 PNG 和对应提示词。图像工具的再次生成不保证逐像素一致；已归档 PNG 才是本轮评审对象。文字是生成的衬线风格参考，不能当作已经安装或精确使用了 Cormorant Garamond。后续若采用此方向，需要在可编辑工程中重绘矢量轮廓、选取并归档实际字体及许可，再制定连续运动；本轮没有提交新的动画源码或成片。
